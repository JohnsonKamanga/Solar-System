## Application Idea
A solar system application built with c++ and OpenGL

## Key Features
Four planets, namely Mercury, Venus, Earth and Mars. The sun and the moon are included as well

The view angle can be adjusted using the mouse.

Camera position can be adjusted using the WASD keys

Each celestial body is rotating about it's y axis 

Each planet rotates around the sun. The moon rotates around the Earth as well as the sun

A combination of directional light and a spotlight were used as lighting sources. 

Ambient, diffuse and specular lighting was applied to all celestial objects
